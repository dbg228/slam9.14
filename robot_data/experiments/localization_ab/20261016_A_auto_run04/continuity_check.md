# A 组第 4 次实车测试与连续性检查

本次为失败试次，不是完成的 2 m 定位精度试验，不得与完整 A/B/C 试次混用。

## 实车结果

- 控制仍为固定 `linear.x=0.15 m/s`、所有其他速度分量为零；距离阈值 2.000 m。
- 动捕基于配置中的 Tracker0→base_link 外参换算机器人参考点。
- 动捕位移 1.687699837 m 时因 `mocap_stale` 触发零速度。
- 停稳后参考点位移均值约 1.718660243 m；停止后的录包尾段完整。
- 未关闭或放宽 0.20 s 动捕接收保护、指令保护和底盘 0.25 s 超时。
- 动态时间偏移仍未独立验证，报告中的动态误差只能视为初步结果。

## 停车事件附近的证据

| 数据 | 停车事件附近的间隔 |
|---|---:|
| VRPN 原始话题，按 bag 接收时间 | 0.2499 s |
| VRPN 原始消息 header | 约 0.2499 s |
| 规范化动捕话题，按 bag 接收时间 | 0.2484 s |

空档前、后，原始消息 header 到 bag 接收的延迟都约 0.1 ms。
规范化消息相应延迟约 2.5 ms、0.8 ms。因此这个事件不能仅归因于规范化节点。
注意原始 header 使用 Ubuntu VRPN 回调时钟，并非相机曝光时间；上述证据不能定位相机端丢帧，
也不能直接区分 Windows 输出、网络传输与 Ubuntu VRPN 客户端调度。
