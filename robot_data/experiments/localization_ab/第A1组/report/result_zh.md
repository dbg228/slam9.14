# A 组第 10 次：47.15° 固定外参下的新包验证

本轮已完成，小车因 `target_reached` 自动停车，继续记录完整 5 秒停车尾段。原始数据保留在 `../bag/`。没有自动倒车或执行下一轮。

## 试验设置与来源

- A 组仅使用 FAST-LIO 局部里程计，没有 NDT、Nav2 或动捕定位反馈。动捕只用于统一 2 m 距离停止触发和离线参考。
- 用户于 2026-10-16 报告实测安装 yaw 为 +47.15°；发车前固定为 `0.8229227423153264 rad`，平移保留 `[0.37, 0.28, 0.15] m`。
- 该角度此前也曾由 run09 反推为候选值；run09 不能用于独立验证该角度。本轮另录新包，后处理不根据本轮运动轨迹重新拟合安装角或尺度。用户实测的原始量具记录尚未提供。
- Tracker0→base_link 固定外参保留 `[0, 0, -0.18] m`、单位旋转，先补偿刚体安装偏移再比较底盘点。
- 已停车重启 FAST-LIO 及其桥接，向现有 robot_state_publisher 更新 robot_description，没有新增冲突 TF 发布者。
- 本轮开始前发现底盘已被重新启动，实验准备程序将运行时 watchdog 从 100 s 重新 configure 为 0.25 s；停止原 teleop 节点，未请求回零或修改底盘源配置。
- 发车前连续性检查共 1989 条动捕消息，最大间隔 59.72 ms，没有超过 200 ms 的间断；静止最大 XY 变化 0.195 mm。未改变网络设置或放宽安全门限。
- 指令仍为车体 `linear.x=0.15 m/s`、`linear.y=0`、`angular.z=0`；这是指令值，不保证实测车速严格等于 0.15 m/s。

## 坐标链与插值复核

从新包中提取 307 个共同时间戳，确认：

- 静态 base_link→imu_link 外参为 `[0.37, 0.28, 0.15] m`、yaw +47.15°。
- 原始 camera_init→body 与桥接后的 odom→base_link，其 yaw 差在数值精度内恒为 47.15°。
- 桥接 XY 与配置外参逆变换公式一致，A 组输出 XY 与记录的 odom→base_link 一致。
- 使用定位测量时间戳进行动捕位置与四元数插值，观察到的最大插值区间约 50.016 ms，未跨越配置的 0.10 s 上限。
- 只使用运动前 3 秒静止窗口估计一次固定 SE(2) 对齐；该窗口不计入统计，不使用整段轨迹配准、不拟合尺度。

位移方向和长度分解采用静止起点均值与停车尾段均值，仅用于诊断，没有重新旋转测试轨迹或替代正式误差分数。本轮端点位移长度差约 1.25 mm，横向差约 0.94 mm。

新结果支持之前的大部分厘米级横向差与固定航向外参有关，而不是简单的 FAST-LIO 两米长度漂移。但是两轮之间也重启了 FAST-LIO、重新摆放了起点，不能把差值严格归因成某个单独参数的确定因果比例。单次直行不能证明旋转、其他方向、不同起点或长距离下同样精确；需要固定外参后重复试验验证。

## 时间与精度边界

动捕仍使用 Ubuntu 接收时间，`timing_verified=false`、偏移配置为零。上述动态 RMSE 是当前时间配置下的起始对齐相对定位误差，不是已认证的毫米级绝对精度。停车终点参考静止性检查通过，2–5 秒尾段参考最大半径约 0.513 mm；终点结果较少受普通固定传输延迟影响。

图中停车附近出现约 0.1° 的残余 yaw 差，已计入总体 yaw 指标，没有删去该段。

结束后另行观察 4 秒收到 127 条动捕消息，XY 最大变化约 0.086 mm；未发现 `/nav/cmd_vel` 或 `/teleop/mode` 发布者。本观察仅确认当时静止，不代表下一轮发车前已通过连续性检查。
