# RA-L 第一轮：研究问题、候选贡献与证据边界

日期：2026-10-19。依据当前工作区代码、既有实验报告与审计、原始论文和官方资料整理。本轮未启动机器人、未修改算法或原实验记录，也未重新采集实验；下列数值来自所链接的既有报告。另以冻结矩阵和三位置原始95对pairs重算静止XY/3D RMSE，得到7.784793962/16.317017238 mm，与报告一致；其余实验未全部重新播放或复算。本文26个本地材料链接均已检查存在。历史说明和最新审计冲突时，采用最新审计，并保留历史来源。

用户口述的“NDP”暂按代码中的 **NDT（Normal Distributions Transform）** 理解。以下明确区分已实现、已实测、仅仿真、计划和待核实。方法名称均为工作名称，不代表已确认创新性或名称唯一性。

## ① 一句话研究问题

**How can a mobile robot initialize LiDAR–inertial navigation and use intermittent motion-capture observations for boundary inspection when external reference coverage is limited, while separating localization error from path-following error?**

中文：在动捕仅覆盖局部区域时，如何利用其完成激光惯性导航初始化和间断纠偏，并在边界巡检中区分定位误差与真实路径跟踪误差？这是研究目标，不是现有实验已证明的结论。

### 定位方法应如何准确命名和描述

建议使用上述描述性名称。**冻结的是坐标变换；map仍为首次FAST-LIO建图原生世界，并未把整张PCD转换到动捕世界。**

统一令 `T_A_B` 将B系坐标变换到A系；M为动捕世界，B为base_link，I为IMU，map=F₀为首次建图世界，O为重启LIO局部世界。实现使用：

```text
T_M_B   = T_M_Tracker × T_Tracker_B
T_F0_B  = T_F0_I × inverse(T_B_I)
T_M_map = mean_static_pairs(T_M_B × inverse(T_F0_B))
T_map_O = inverse(T_M_map) × mean_static_pairs(T_M_B × inverse(T_O_B))
```

`mean_static_pairs`在实际代码中是逐对变换的SO(3)旋转均值与平移算术均值，不是对整条测试轨迹进行最优对齐；不拟合尺度。首次关系与每次启动关系分别归档。该过程需要已确认且保持不变的刚体安装外参、动捕轴/原点和有效配对，动态时间延迟仍未独立标定。见core.py的estimate、initial_map_odom及方法文档。

### 锚定定位：可报告7.78 mm的局部静止一致性，不能认证独立绝对精度

一场重启定位会话，三个留出静止位置各31/32/32对，共95个有效配对样本：XY RMSE **7.7848 mm**，3D RMSE **16.3170 mm**。初始化同点复测已排除。95对不是95次独立实验，三个位置也不是三次独立重启。初始化和评测共享同一map↔mocap关系，不能独立验证世界标定；没有PCD/NDT地图匹配，不能称历史地图重定位精度。见[三位置实测报告](../../robot_data/experiments/mocap_initial_mapping/20261017_native_01/validation_sessions/20261017T085200Z_three_static_points/report.md)。

同版本动态前进记录有五次成功，跨趟XY RMSE为6.919±2.058 mm，共八次尝试，包含未发车的预检失败；会话和发布设置也有变化，不与ABC构成严格配对优劣证明。见[动态汇总](../../robot_data/experiments/mocap_initial_mapping/20261017_native_01/dynamic_trials/forward_summary.json)。

### 整圈巡检：局部纠偏收益与终点过补偿同时存在

最新依据为[2026-10-19三组审计](../../robot_data/experiments/full_map_loop/20261018_relocated_01/three_group_audit_20261019/data_audit.md)。

|记录|中途XY定位残差|终点XY定位残差|限制|
|---|---:|---:|---|
|第1组NDT|未评价|12.99 mm|只有3帧；NDT参与配准，且对窗口敏感|
|第2组正式trial_02|缺测|13.36 mm|无全程独立真值|
|第2组0.60 m外扩测试版|181.98 mm|10.44 mm|并非正式版重复；原生LIO存在长缺录|
|第3组0.60 m外扩|218.37→2.31 mm|176.95 mm|中途一次持久全局更新；长停留、低速及新鲜度门槛变化|

第3组纠偏后2.31 mm来自后续时间窗，但仍为几乎同一物理站位，支持短时局部一致性。对同一批终点保存位姿应用旧/新变换，XY RMSE为27.384/176.945 mm，显示持久补偿的过补偿；旧变换离线值不是无纠偏重跑的结果。不能把此结果写作“局部纠偏已改善整圈轨迹”。

第3组全样本地图估计跟踪距离RMSE为85.43 mm，排除明确停车后为155.93 mm；停车占约71.7%。两者均是内部map位姿到参考路径的距离，不是全程动捕真值误差。采集器还存在缓存TF按当前时间重复写入的问题。组间地图、路线、边距、速度和停车不一致，不能排名算法。0.55 m测试版的终点刚体姿态异常，不应作为有效精度结果。

### 几何与控制结果的边界

栅格边缘确实用于建筑主方向估计与显示对齐，但未直接自动生成巡检多边形；当前多点边界由人工点击指定。单一多边形外环、人工路线顺序与真实多区域排序优化应区分。路径圆角离散采样不等于连续曲率或动力学可行性保证；偏置距离不自动包含车体足迹、地图误差和跟踪误差。没有传感器视场模型，不能用路径经过率代替巡检覆盖率。

MPPI候选机制的主实验为4控制器×3路线×2执行设置×3噪声种子=72轮合成闭环；每控制器/设置9个固定场景记录。模型失配设置中，弯道横向RMSE的条件均值为完整方法1.461 mm、原生MPPI 5.731 mm；名义设置中纯跟踪器0.401 mm优于完整方法0.893 mm。不能声称采样在所有设置均有收益。完整方法的角速度命令导数RMS高于原生基线，不能写整体更平滑。仿真参数尚未实车辨识，计算耗时未回灌为额外plant延迟，shadow入口仍把平滑器状态与待执行队列置零。见[主结果](../../tests/turning_mppi/RESULTS.md)、[平滑性](../../tests/turning_mppi/paper/tables/table02_smoothness.md)、[在线入口](../../tests/turning_mppi/shadow_node.py)。

### 必须分别报告的指标

以下为评价口径及待补充的统一报告要求，不是新控制或估计算法。令Pxy取平面位置；RMSE对每轮的有效样本计算，再汇总各轮，不把帧数当独立重复。

|指标|定义|位姿与参考、坐标和时间/区间|
|---|---|---|
|定位位置残差|e_loc,i = norm(Pxy(p_est,i − p_ref,i))；RMSE = sqrt(mean(e_loc,i²))|B/base_link对B，均换到固定map；动捕经冻结外参转换。ABC另有起始SE(2)对齐，只称相对误差。动态锚定报告最近邻≤25 ms、不插值不重拟合；曝光偏移未知。静止位置数、样本数和会话数分别报告|
|到路径距离|e_path,i = min over finite segments norm(p_i − projection_segment(p_i))|路径为下发的冻结参考线。现全图p_i为map估计，故为估计轨迹偏差；当前时间是轮询时间，未保存TF源时间。后续真值跟踪仅在有效独立参考覆盖区报告，运动与停车分开|
|带符号横向误差|e_lat,i = n_iᵀ(p_i − q_i)，q_i为最近有限线段投影，n_i为该段左法向|与到路径欧氏距离分列；有限线段端点处不必相等。MPPI仿真弯道指标使用合成真实状态、同仿真时钟与预定义弯道区间|
|航向误差|e_yaw,i = wrap(yaw_i − yaw_ref,i)|定位航向用同期动捕；跟踪航向用参考路径切线/存储yaw，分别命名。弧度内部计算，报告角度时标单位|
|终点定位残差|在预定义终点静止窗上统计e_loc|全图表中的12.99/13.36/176.95 mm均属此类，不是相对导航目标的到点误差。ABC使用停止后2–5 s尾窗|
|目标到达误差|e_goal = norm(Pxy(mean(p_ref,final) − p_goal))|须用真值静止位置相对冻结目标，另报航向及允许窗；现有定位残差表不能替代，跨组统一结果待核实|
|静止抖动|报告原脚本定义的最大静止半径 max norm(p_i−mean(p)) 或明确的标准差|各源在预先指定静止窗内单独计算；不以散布替代绝对偏差。若新增RMS散布需从原数据重算，并注明为新增统计|

对应实现：[固定变换定位误差](../../tests/mocap_anchored_mapping/mocap_anchored_mapping/core.py)、[三静止点复算](../../tests/mocap_anchored_mapping/tools/static_points_report.py)、[有限线段投影](../../tests/full_map_loop/tracking_report.py)、[ABC指标边界](../../robot_data/experiments/localization_ab/第B1_three_legs_mount47p15/01_forward/report/report.md)。当前记录不满足的时间/独立真值要求应如实标待核实，不能通过重新标记旧数据补足。

## ⑤ 按优先级补充实验

以下全部是建议开展的实验，不是已完成事项。重复数建议至少每条件5次独立启动/完整试次作为首轮设计，最终次数应由效应大小、变异和统计设计确定；不能把“≥5”写成显著性保证。

1. **测量链与时间链验收。** 在两处覆盖区布置多位置、多朝向与空间留出点；冻结并追溯Tracker→base、IMU→base、动捕原点/轴、map版本。尽可能引入独立测量地图控制点。复核刚体重识别后的原点/轴；记录源时间，拒绝陈旧或重复TF，独立检查跨源延迟，分别报告静态与动态不确定性。
2. **定位与纠偏模型的可识别性。** 同一会话往返不同位置/朝向，观察单个停点残差是否具有全局恒定刚体偏差性质；留出空间验证点，在更新前后检查多站点。先定位第3组过补偿的条件，再决定采用何种新机制。SE(2)限制、门控、局部有效补偿或融合均只能作为待研究方案，不能提前写成实装。
3. **统一条件的定位实车对照。** 固定地图/物理路线/参考点/速度/边距/停留/有效窗，交错顺序比较当前NDT、仅动捕初始化、初始化加间断纠偏。独立启动，多次完整重复；保留失败与所有预注册窗口，报告每轮定位、目标到达及有效覆盖内真实跟踪结果。只改一个因素以支持归因。
4. **控制执行链辨识与实车消融。** 记录平滑器前后、仲裁后命令及真实响应，辨识延迟与响应并留出验证；实现在线队列/状态重建。在同定位、同路径和相近速度曲线下比较原生MPPI、约束匹配基线、纯跟踪器、完整候选；分别移除预瞄、滞后补偿、执行模型和残差搜索，动态真值覆盖转弯；计入真实计算延迟和失败。
5. **几何规划的独立评价。** 凸形、凹形、窄通道、相邻障碍及不同边距；比较人工航点和标准buffer，报告边距偏差、足迹碰撞、曲率、路线长度、规划时间、人工输入量与失败。若主张多区域，先提供区域集合、连接与排序算法；若主张巡检覆盖，先定义传感器视场/有效观测条件及覆盖指标。

## 待核实信息

- 口述普通三点、固定路标、新方法各自对应的准确试次与材料；是否另有未归档的独立路标测量。
- 是否有另一版自动边缘生成巡检边界、多区域连接与访问排序实现；当前审计只覆盖所链接版本。
- 动捕计量标定记录、刚体安装外参可追溯证据、跨源时间偏移与曝光延迟。
- 第3组中途空间失配的主要来源，以及最终计划采用的纠偏作用范围；现有数据不能唯一归因。
- 新控制器是否有未归档实车闭环；当前可见证据为合成仿真与shadow自检。
- 各条件独立会话数、冻结配置及成功/失败纳入规则；目标到达误差、运动区真实跟踪误差的统一结果尚缺。

## 可能受到的审稿质疑

- 核心机制相对刚体配准、标准map→odom修正和已有外部测量融合究竟新增了什么？
- 动捕既用于初始化/校正又用于评测，如何区分一致性与独立绝对精度？
- 为什么中途残差降低而终点恶化？修正代表全局偏差还是局部空间失配？
- 路线、地图、速度与停车改变后，如何归因于算法？样本帧是否被误当独立重复？
- buffer和人工路线选择如何构成多区域几何规划贡献？巡检任务成功与覆盖率如何定义？
- 若纯跟踪器在名义模型更好，采样控制的必要性由哪些失配条件、实车消融与计算预算支持？

## 本轮实质性技术修订建议

1. 将“地图建在动捕系”修正为“原生地图经冻结变换与动捕锚定”，以匹配现实现。
