## 距离与曲线含义

路程从正式运动指令开始，到最后一次非零底盘指令后的零指令及 1 秒停车余量结束；排除三点标定和出发等待。积分使用连续 LIO 底盘中心位置，不计 map→odom 全局修正。由于 `/tf` 底盘帧丢样，使用同包 `/tf_lio_raw` 按原安装外参还原，561 个重叠时间戳最大差异约 1.78e-15 m；恢复后共 3569 点，无超过 0.5 秒缺口。不插值、不拟合、不改源时间戳。

63.739 m 是含噪声、漂移及局部跳动的**LIO 估计路程**，不是全程动捕实测距离，也不是参考路线长度。跟踪误差使用地图估计轨迹对参考路径的最近有限线段偏差，不做轨迹对齐；与动捕定位误差分别报告。巡检节点 Path 时间戳是采样时刻，未保留 TF 源时间，不用于动态动捕同步。

初始、终点曲线仅连接真实配对样本，覆盖区外无动捕真值，不补造全程定位误差。终点迟到 NDT 数据只和同源时刻有效静止动捕历史配对；保留接收延迟，不能据此声称实时控制新鲜度达标。曝光时延和跨设备时偏未独立测定。
